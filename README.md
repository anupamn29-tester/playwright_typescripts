# Playwright TypeScript Automation

A simple JavaScript automation project using Playwright and TypeScript concepts.

## Description

This repository is a small TypeScript starter project for learning automation basics and practicing simple scripting with Node.js.

## Prerequisites

- Node.js 18+ installed
- npm available in your environment
- Git installed and configured

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/anupamn29-tester/playwright_typescripts.git
   cd playwright_typescripts
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Installation

Run the following from the project root:

```bash
npm install
```

## Usage

- Open and edit the sample file in the `TypeScript` folder.
- Add new scripts or examples as needed.
- Run your TypeScript files with your preferred TypeScript runtime or compiler.

## Notes

- The project currently depends on `prompt-sync` for simple command-line prompts.
- Add Playwright and TypeScript dependencies later if you expand this automation project.
